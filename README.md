# gojyuon.py
![test](https://github.com/Akari0709/robosys2025_1/actions/workflows/test.yml/badge.svg)
- このプログラムは、標準入力からひらがな1文字を受け取り、五十音順で次の文字を標準出力に出力するツールです。
- 結果は画面上に書き出されます。
## 使用方法
- 実行: echo "ひらがな" | ./gojyuon
- 実行すると結果が表示されます。
  - 例:
    - echo さ | ./gojyuon
    - し
    - echo の | ./gojyuon
    - は
