# gojyuon.py
![test](https://github.com/Akari0709/robosys2025_1/actions/workflows/test.yml/badge.svg)
- このソフトウェアパッケージは、3条項BSDライセンスの下、再頒布および利用が許可されます。
- このプログラムは、標準入力から受け取ったひらがなの五十音の次に来る五十音を表示するツールです。
- 結果は画面上に書き出されます。
## 使用方法
- 入力: python gojyuon.py
- 実行後、次のように表示されます：
  - 文字を入力してください（Ctrl+C で終了）：
- 文字を入力し、入力が終わったら Ctrl + C を押して終了します。
- 実行すると結果が表示されます。
  - 例:
    文字を入力してください（終了は Ctrl+C）: さ
    し
    文字を入力してください（終了は Ctrl+C）: ど
    五十音以外です
    文字を入力してください（終了は Ctrl+C）: ^C
    終了します
## 必要なソフトウェア
- Python
  - テスト済みバージョン: 3.7 ~ 3.10
## テスト環境
